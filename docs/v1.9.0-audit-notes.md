## 踩坑（均已修，防复发）

1. **Python str.replace 锚点不命中 = 静默跳过**。守卫函数插入失败但 `sh -n` 通过（语法层面无错，运行时才炸 require_deps not found）。铁律: replace 后必须 assert 新内容在文件里。
2. **LuCI E() 嵌套数组 children 被 toString**。`E('div', {}, [node, [node2, node3]])` 中嵌套数组渲染成 `[object HTMLDivElement],[object...]`。单层数组可以，嵌套必须 `[a].concat(deps)` 拍平。v1.8 的冲突块 `conf.map(...)` 数组分支从未被真机渲染验证过——同类隐藏雷，靠"报告①依赖层"新断言抓出。
3. **E2E mock 缺依赖的通道**: LuCI view 模块作用域函数在 page.evaluate 里拿不到（`L.require('view.netsteer')` 不给类）。正解 = Playwright route 拦截 ubus 请求返回假 audit 输出，走真实 UI 全链路。细节:
   - post_data_json 是**批次数组**（不是单对象）
   - 调用形态 `body[i]["params"][3]`，键是 `command`（不是 cmd）
   - route pattern 必须 `re.compile(r"/ubus/")` — 实际 URL 是 `/ubus/?1693876...`（尾斜杠+查询串），glob `**/ubus*` 的 `*` 不跨 `/` 匹配不上
4. **shell 守卫测试**: 沙箱拷贝 netsteer-mode + sed 替换探测路径（/usr/lib/sqm/run.sh → /tmp/gt/...、/proc/modules → /tmp/gt/proc_modules），隔离验证缺/半缺/全无三态。
