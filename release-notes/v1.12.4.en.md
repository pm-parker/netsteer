# v1.12.4 — Master Switch + Thunder-style A/B Gain Comparison

## Highlights

One-click "on vs off" comparison. Turning the master switch off measures the system baseline first (real ping latency + interface throughput sampling, 8s window); once re-enabled the page shows the true gain versus that baseline — every percentage comes from on-router measurement, nothing is fabricated: idle links honestly report "latency unchanged", congested links reveal the real benefit of cake shaping + per-core steering.

## Added

- **Master switch** (top of overview): off = disable all optimization and restore system defaults (SQM config kept, one click back); on = restore last mode. Confirmation dialog guards accidental taps
- **netsteer-bench baseline meter**: latency + up/down throughput measurement, baselines persisted to uci (bench_off / bench_on), survives reboots
- **Measured gain readout**: latency delta vs baseline (e.g. ↓11%), or "latency unchanged (X ms)" when equal
- **Throughput chart gain visualization**: "vs baseline" dotted line + zero-gain reference line
- Router icon moved left of the "Router Core" label (24px native size)

## Fixed

- Master switch & baseline reads moved to the uci channel: fixes "reading…/operation failed" false failures caused by background measurements hogging the rpcd exec channel
- Throughput chart crashed rendering grid lines when all samples were empty (NaN y-axis range)
- Toggle control squashed by theme button rules (knob derailed, track collapsed) — style specificity hardened
- Left-most x-axis time label (-7.5m) clipped by plot area
- Removed three redundant tab subtitle lines (overview / smart / expert)
