# v1.18.0 — 判定下沉 + 首次使用向导 + 场景联动

发布日期: 2026-11-09
定位: v1.18 P0 三任务收官 — 判定与硬件解耦页面、3 步可用向导、场景×档位自动联动。

## 新增

### 判定下沉后端 (b22c808)
- 新增 `sense.awk`: JS 判定规则 1:1 移植的独立 awk 引擎 (三级识别链/量门槛/打分/宁漏勿误)
- 新增 `netsteer-qos sense-daemon`: 常驻判定守护, 30s 低频轮询 + 连 2 窗防抖 + 原子写 `/tmp/netsteer/sense.json`
- init.d 幂等拉起 (pid 存活检查); **页面关闭判定不中断** — D14 联动自此不依赖 LuCI 页面开着
- `json2tab.awk`: dnslog JSON → 七字段 TAB 转换器 (netsteer-qos 与单测共用单一来源)
- 单测抓出并修复 3 个引擎级 bug: 行尾 gsub 剥空字段丢裸 IP 流量 / awk 未初始化下标丢端口表首行 / awk 裸 VAR 非环境变量 (ENVIRON 才生效)

### 前端消费后端判定 (37446ea)
- 场景卡优先读后端 `sense.json` (新鲜度窗 `interval*3+10s` 内信任后端防抖, 不做本地二次防抖)
- 缺失/过期回退本地判定 (原路径更名 localSense, 行为不变)
- `verdictToRes` 顶层纯函数: 后端 ev 计数 → 渲染层 evidence 形态

### 设备排除 + 场景联动 (408a8dc)
- `sense_exclude` (uci): 采样过滤排除设备 (网心云类对外服务设备根治误判; 真机实证 streaming 证据 1→3)
- `exclude.awk` + JS 回退路径同款过滤
- `sense_linked` (uci, 默认关): 稳定档 (standard/latency) 时按判定自动切档
  - work/gaming → latency; 其余 → standard; 只接管 standard↔latency 区间
  - 用户手选 (steering/p2p) 不覆盖; 防抖未确认不触发; 真机双向验证

### 首次使用向导 (本轮)
- 新增 `netsteer-wizard`: probe (硬件探测+并发测速校准+分级) / apply (应用档位+SQM 校准值+完成标记) / skip
- **3 步向导弹层**: 检测 → 推荐 → 一键开启; 老升级用户 (autotune_done=1) 不再打扰
- **D20 设备分级**: T0 弱设备 (≤2核或≤256MB) 只推「纯分核加速」零整形; T1/T2 推「均衡」
- **D13 校准并入**: 并发 3 路 CDN 测速 8s 窗取最大吞吐, ×0.85 写入 SQM
- **测速失真防线**: 测得值 < 线路规格 1/4 (CDN 单连接限速嫌疑, 千兆线路实测仅 24Mbps) 时转「套餐档位点选」(100/200/300/500/1000M, 默认选最近档)
- SQM 校准参数化: `netsteer-mode` 接受 `WIZ_DL/WIZ_UL` 环境变量覆盖 (未设不动现值); 顺修 sqm_migrate 节类型提取引号 bug
- WAN 协商速率识别链: `network.wan.device` → 默认路由口 → 物理口兜底 (pppoe 虚拟口无 speed)
