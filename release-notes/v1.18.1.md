# v1.18.1 — D20 参数自适应 + 联动/排除 UI

发布日期: 2026-11-10
定位: v1.18 范围收口 — Task 4 参数自适应落地 + Task 3 联动/设备排除的用户面补齐。

## 新增

### netsteer-tune (D20 参数自适应)
- 新增 `netsteer-tune <tier|show>`: 按档写三组参数并持久化
  - **nf_conntrack_max 按内存自适应**（根治满表断网）: `clamp(mem_mb×512, 16384, 262144)`
    — 128MB→65536 / 256MB→131072 / ≥512MB→262144 顶格；buckets=max/4；
    运行时 sysctl -w + `/etc/sysctl.d/10-netsteer.conf` 开机重放
  - rfs_sock_flow_entries: T0 16384 / T1 32768 / T2 65536
  - sense-daemon 采样间隔: T0 60s / T1 30s / T2 20s（kill 后等退干净再 restart，防幂等跳过）
- 向导 apply 自动调用（分级完即按档调参）；`show` 子命令输出当前参数 JSON

### 智能模式页两块新卡 (D14 用户面)
- **自动切换卡**: 联动开关 + 一句状态行（"正在检测: 看视频 → 将自动切到「低延迟优先」"）；
  用户语言呈现，不暴露档位字母；手动选的 P2P/极速档明示不改动
- **排除设备卡**: IP 列表（点击移除）+ 输入添加（IPv4 校验）；
  保存后 daemon 下一轮采样自动生效（每轮重读 sense_exclude，无需 reload）

## 修复
- netsteer-tune 首版 daemon 换活竞态：kill 后 init.d 幂等 restart 看到未退净进程会跳过拉起
  → kill 后最多等 3s + 强制 9 号兜底 + 删 pid 再 restart
