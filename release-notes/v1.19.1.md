# v1.19.1 — 交互一致性修复 + 配置写入通道重建

## 修复

**「自动切换」报错根除**：部分 OpenWrt 构建上 ubus 的 `uci.apply` 方法异常（LuCI 页面报「ubus uci.apply 失败：[5]」）。本版把插件全部配置写入改走 uci 命令行通道（新增 netsteer-cfg 脚本，写入即落盘），同类报错一次根治。

**「自动切换」开关并入智能模式**：独立开关概念冗余——都叫智能模式了，不该再问"要不要自动"。现在智能模式开启即自动联动：检测到看视频/打游戏自动切到更合适的模式，闲时恢复均衡，您手动选的档位始终优先。场景卡里的说明文字即全部，无需理解第二个开关。

**顺带修复**：总开关关闭时联动不再拉起优化（此前"关闭"状态下场景切换可能把优化重新打开）；智能模式页不再出现 "null" 文字（控件渲染缺陷）。

## 变更明细

- 新增 `netsteer-cfg`：netsteer 配置统一写入脚本（uci set + commit 即时落盘，绕开异常的 ubus apply）
- 前端 6 处配置写入全部切换到新通道（自动切换/识别排除表/设备加速/P2P 直通/自动调优标记/批量管理）
- 场景联动默认开启（`sense_linked` 缺省 0→1），且总开关 off 时不接管
- UI：删除「自动切换」独立卡片，智能场景卡新增一行联动说明

## 质量门

单测 440 项全绿（core 302 / cfg 18 / bulk 33 / sense 21 / tune 15 / qos-awk 9 / feed 11），e2e 16 项真机全绿，R5C 真机终装 + md5 对账通过。
