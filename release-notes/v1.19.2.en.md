# v1.19.2 — UI refinement: badge / control / icon system redesign

## UI

**Badge system redesigned**: card badges now follow a closed vocabulary — they carry state and scale only (未开启 / 已开启, optionally · N 台), never IP fragments or slogans. New badge variants: a neutral tag style (capability labels such as "AI 智能识别", no dot) and an icon-tag style (the scene icon itself is the marker).

**Control language unified**: buttons on the smart tab collapse into two states — green outline for affirmative actions (enable / add / update), muted gray for stopping actions (disable / close). Device chips become one capsule design (suggestions carry a weakened ＋, selected entries a weakened ×). All three suggestion areas (suspected gaming devices / suspected background usage / detected traffic) share the same inset band container. Every input follows the placeholder-only pattern; the three cards' input rows now align on the left edge.

**Scene icons**: the text glyphs (◈☂▶⇩) are replaced with hand-drawn 24px line SVG icons (gamepad / video camera / play-in-circle / arrow-to-tray / globe). Strokes follow the text color and adapt to light and dark themes automatically; the geometry is original artwork, free of third-party licensing, and fully self-contained in the package for offline use. Applied to the overview scene tile, the scene headline chip, and the evidence chips.

**Fixes**: the throughput chart's X-axis time labels were visually squashed by the non-uniform SVG stretch — labels now live in an HTML row below the chart and can no longer distort. Also fixes a latent defect: LuCI creates SVG tags without a namespace, so the real-time latency curve had never actually rendered; it now does.

**No functional changes**: scheduling logic, detection engine and configuration options are untouched by this release. Upgrade and go.
