# v1.19.2 — 界面精致化：徽章/控件/图标系统重设计

## 界面

**徽章系统重设计**：右侧状态徽章改为封闭语义集——只承载「状态 + 规模」，措辞统一为 未开启 / 已开启（可带 · N 台），不再混装 IP 尾段与宣传语；新增标签变体（无圆点的能力标签，如「AI 智能识别」）与图标标签变体（场景图标即标记）。

**控件语言统一**：智能模式页按钮收敛为两态——绿描边 = 肯定操作（开启/添加/更新），灰静音 = 关停操作（关闭加速/关闭）；设备标签统一为一种胶囊（建议带 ＋、已选带 ×，弱化尾段符号）；建议区（疑似游戏设备 / 疑似后台占用 / 识别到）统一同款内嵌条容器；全部输入框统一 placeholder 式排版，三卡左缘对齐。

**场景识别图标**：文字符号（◈☂▶⇩）换为手绘 24px 线性 SVG 图标（游戏手柄 / 摄像机 / 圆圈播放 / 箭头入托盘 / 地球），描边跟随文字颜色、深浅主题自动适配；几何原创、无第三方版权，包内自包含离线可用。总览「当前场景」格、场景大标签、证据 chip 三处同步。

**修复**：吞吐量图表 X 轴时间刻度被非等比拉伸导致文字压扁——刻度移出 SVG 改为 HTML 行，永不变形；顺带根治一个潜伏缺陷：LuCI 构造 SVG 标签时不带命名空间，「实时出口延迟」曲线此前从未真正渲染过，现已修复。

**无功能变更**：调度逻辑、判定引擎与配置项与本版无关，升级即用。
