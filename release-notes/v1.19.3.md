# v1.19.3 — 判定引擎修复：L2 识别链、带宽腐蚀与 DSA 适配

> 本版核心修复来自外部贡献者 PI-Cursor DS 的全库代码审查（PR #1），经维护者行为级独立审计后合并。

## 修复

**P0 · 场景识别 IP 段/端口链全失效**：`sense.awk` 两处变量链断裂（分类写入局部变量、调用方读从未赋值的全局名），导致游戏 IP 段与端口规则两条识别链 100% 落空——裸 IP 直连流量（游戏/P2P 的核心形态，无域名、无 SNI）此前永远判不出场景。修复后裸 IP 直连正确命中游戏段，非游戏 IP 不误判。同一处还有一个跨记录累乘缺陷：网段基准值逐条翻倍溢出，即使分类修好也匹配不上，已一并修复。

**P1 · 带宽反复切换被腐蚀**：进入延迟优化档时带宽 ×0.9 写回但不留基准，反复切换档位会让 SQM 带宽一路缩水（实测 4 轮 -27%）。现首次降速前把真实带宽存档，此后降速与恢复都以存档为基准，标准档恢复原始带宽。

**P1 · 「vs 基线」增益层从未渲染**：吞吐图增益层引用了错误的变量名，计算结果为 NaN 被图形层静默吞掉。修复后 A/B 对比的增益线正常绘制。

**P1 · netsteer-apply 参数被静默吞掉**：任何调用一律全量应用，传参无效。现支持 `apply / clear / preset {all|balanced|off} / auto`，未知参数报错退出。

**P2 · DSA 命名设备适配**：吞吐采样与分核应用此前硬编码 `eth0/eth1`，在 lan1/wan 命名的现代 OpenWrt 设备（DSA 交换芯片主流形态）上采样为零、配置失效。现通过 sysfs 物理口探测与 WAN 角色判定（ubus → uci → 默认路由逐级回退）动态适配，pppoe-wan 等虚拟口正确归入承载层。

**P2 · 状态文件原子写**：场景状态落盘改为临时文件 + 原子替换，前端轮询不会再读到半截内容。

**CI · 版本守卫加固**：PR 事件的 `N/merge` 引用名此前可穿过版本守卫使构建崩溃；现仅接受完整 `N.N.N` 形态，构建脚本对版本串做字符白名单校验。

## 验证

单测 413 全绿（场景识别 21→26，含裸 IP 直连、非首条 IP 规则、端口链协议不匹配等新增断言）；真机 e2e 16/16；核心修复均在真实路由器上复现验证（修复前裸 IP 判 normal → 修复后判 gaming）。本版无新功能，调度逻辑不变，升级即用。
