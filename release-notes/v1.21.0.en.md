# v1.21.0 — Scene-injection e2e + lint gate

## Highlights

Scene detection finally has automated verification. Previously, changing the detection logic in `sense.awk` meant manually generating traffic on a live router and eyeballing the result — now there is a dedicated injection test: real traffic → observation plane → engine verdict, end to end.

JS lint is now wired into CI, with the legacy unused-declaration backlog cleared to zero and gated.

## Added

- **`tests/e2e/inject_test.py` — scene-injection e2e** (standalone script; requires two compute pods, auto-skips without them)
  - Streaming scene: real download of `www.youtube.com` (`--resolve` pins the real IP to bypass fake-ip while keeping the SNI domain), polling until the engine produces `ev_stream_dom`
  - Download / gaming scenes: UDP floods to 6881 (BT) / 27015 (Steam); after switching the observation plane to conntrack, port evidence is verified through the engine
  - Observation plane is restored to `auto` afterwards
  - Wired into `e2e.py --inject` (off by default so CI without pods never false-fails)
- **`.oxlintrc.json` — oxlint config**: `_`-prefixed names are treated as intentionally ignored; four functions covered by unit tests are exempted from `no-unused-vars` (they are invoked via eval-injected extraction in `core.test.js`, not dead code)
- **CI lint gate**: `no-unused-vars` / `no-unused-expressions` must stay at zero or CI fails

## Fixed

- **JS unused-declaration backlog cleared (48 → 0)**
  - 27× `catch (e)` → `catch (_e)`
  - 16× unused params/vars prefixed with `_`
  - 1× ternary-with-side-effects rewritten as if/else
- **Injection-test pitfalls (documented in the script)**
  - `netsteer-qos dnslog` emits JSON; the engine consumes 7-field TSV — the production pipeline `dnslog | qos_json2tab | exclude.awk | sense.awk` (`netsteer-qos sense`) must be used
  - Injected traffic must actually traverse the router's transparent proxy, otherwise the mihomo connection table has no row for the source and domain evidence never appears
  - Connections leave the table when closed — sampling must poll while injection is in flight
  - LAN→LAN traffic bypasses conntrack; port-class evidence must target public addresses
