# v1.22.0 — 负载延迟探测 + 过热保护

## 亮点

### 负载延迟探测（缓冲膨胀，诚实边界版）
总览页新增「缓冲膨胀」卡：一键测"空闲延迟 vs 负载下延迟"，8 流 CDN 下载产生真实下行负载，同窗 ping 采样，差值 + 负载规模（load_mbps）一起落盘。

- 负载不足（<50Mbps）时判 `weak` 并明示"结果仅供参考"——直接来自实测教训：负载没拉起时 0ms 差值是假阴性
- 判定分级：稳定(<10ms) / 轻度(<30) / 中度(<100) / 重度(≥100)
- **诚实边界**：CDN 单流被恒限 ~24Mbps，本机 8 流负载上限 ~200Mbps——千兆线路上本探测验证的是整形健康度与容量下界，不是满载 bufferbloat（满载需 flent 式外部负载源）。README 与脚本头均如实写明

### 过热保护（thermal guard）
`netsteer-check`（每分钟 cron）采样最热温区：

- 数值落 `/tmp/netsteer/health.json`（内存盘，每分钟写不伤 flash；跨阈值事件才写 uci/log）
- ≥85°C：日志告警，10 分钟防刷屏
- ≥95°C：自动降档 steering（过热保护优先于吞吐），事故日志落 `/etc/netsteer/incidents/thermal-*.log`；温度回落**不自动升档**（宁漏勿误），UI 提示手动恢复
- 总览页新增「设备温度」卡：正常绿 / 偏热(≥85°C)无色 / 过热(≥95°C)红

### 其他
- `netsteer-audit` 新增 `health`（温度）、`mtu_fix`（MSS 钳制检出）、`bloat`（探测结果透传）字段
- rpcd ACL 白名单新增 `netsteer-bloat`
- 修复：`for z in firewall.@zone[*]` 被 shell glob 吞掉导致 mtu_fix 恒 0（改 uci show 解析）
