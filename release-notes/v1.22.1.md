# v1.22.1 — 快照与回滚 + 持久变更审计

优先级 3 安全网：所有配置变更可退，变更历史重启不丢。

## 快照与回滚（netsteer-snapshot）
- 档位（mode）/ 总开关与设备加速（qos）/ 向导（wizard）/ 不抢网设备列表（bulk）四类写操作变更前自动快照
- 快照内容：netsteer + sqm 全量 uci、firewall offloading 字段、当时档位；存 `/etc/netsteer/snapshots/`，保留 20 份，同标签 5 分钟去重（防连点/自愈刷屏）
- `restore <id|latest>`：uci 恢复 → sqm restart → fw4 reload → netsteer-apply 重对齐运行态 → **重放 nft 规则层**（P2P 直通按恢复档位重建、游戏通道 qos reapply）——规则不在 uci 里，纯 uci 恢复会漏这一层（真机实测发现并补上）
- 回滚前自动另存 pre-restore 快照：回滚本身可回滚；`/etc/config/*.pre-restore` 兜底防 import 失败
- 不整包恢复 firewall（只还原 offloading 单字段）——整包恢复防火墙风险过高

## 持久变更审计
- `/etc/netsteer/history.log`：save/auto/restore 全记录 + check 的状态变化双写；重启不丢（v1.22.1 前 /tmp 版重启即失是盲区）；2000 行滚动留 800
- 仅 state 变化时写 /etc，不伤 flash
