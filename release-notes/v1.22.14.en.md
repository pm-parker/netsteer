# v1.22.14 — Recognition dataset: independent version line + automatic update loop

This release turns the recognition dataset into an independent version line: the dataset is collected and published weekly, fully decoupled from plugin version numbers. Includes all improvements since v1.22.2 (13 versions).

## Dataset: automatic collection pipeline (core)

- **Weekly auto-update**: GitHub Actions pulls upstream sources every Tuesday 03:00 CST, opens a PR on change, publishes on merge (CDN auto-purged); the router pulls automatically every Tuesday 04:37 with automatic rollback on failure
- **Decoupled from plugin versions**: dataset version = date + content hash (e.g. `2026.11.12-ac3186`); dataset updates never bump the plugin version or create tags
- **Five data sources**: uklans/cache-domains (MIT), Valve official SDR relay API (CS2+DOTA2 aggregated), Microsoft 365 official endpoints API (Teams meeting domains), ngosang/trackerslist (BT trackers), anti-AD blocklist reverse-mapped to streaming platform domains via a curated family table (only family-matched domains are imported)
- **7 dataset files**: game domains / relay IP segments / game ports / download ports / streaming domains / meeting domains / BT tracker domains
- **Douyin & Kuaishou covered**: douyinvod.com / yximgs.com video CDNs verified hitting the streaming scene

## Three-layer dataset update protection

- **Anti-downgrade**: refuses older remote versions with an explicit notice (date-only numeric comparison; hash suffixes never sort)
- **Three-layer validation**: sha256 → semantic validation → engine smoke test; atomic replace only when all pass, automatic rollback otherwise (20 snapshots kept)
- **Upgrade-protection fix**: the self-heal no longer rolls back a freshly shipped dataset after apk upgrades (the old string-comparison could misjudge direction)

## Smart-mode page: automatic new-version detection

- Entering the smart-mode tab silently checks for a newer dataset (once per session, 1-hour throttle); shows a one-click upgrade banner only when one exists — fully silent otherwise

## UI polish (summary of v1.22.2–v1.22.10)

- Network-path card rebuilt: HTML 1:1 rendering fixes SVG-resampling blur; ≤640px vertical topology removes horizontal overflow
- Throughput chart: isolated Y-axis container with nice ticks; brand colors unified (lime = interaction focus / teal = health values)
- Snapshot card rebuilt; bloat card as compact row; touch targets ≥44px; skeleton loaders for empty states

## Upgrade notes

- Install over the existing apk; the dataset ships inside the package (`/usr/share/netsteer/`); data previously updated via feed is adjudicated by upgrade protection
- Default remote: jsDelivr CDN → GitHub raw multi-source fallback; point `uci netsteer.feed.url` at your own mirror if needed
