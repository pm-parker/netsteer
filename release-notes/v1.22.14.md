# v1.22.14 — 识别库数据集独立版本线 + 自动更新闭环

本版把「识别库（场景识别数据集）」升级为独立版本线:数据集每周自动采集发布,与插件版本号完全解耦。含 v1.22.2 以来 13 个版本的全部改进。

## 识别库数据集:自动采集管线 (核心)

- **每周自动更新**:GitHub Actions 每周二凌晨 3:00 (北京时间) 自动拉取上游生成数据集,有变化开 PR 人工过目,合并即发布 (CDN 自动刷新);路由器每周二 04:37 自动拉取,失败自动回滚
- **与插件版本解耦**:数据集版本 = 日期 + 内容哈希 (如 `2026.11.12-ac3186`),数据更新不 bump 插件版本号、不打 tag
- **五个数据源**:uklans/cache-domains 游戏域名库 (MIT)、Valve 官方 SDR 中继 API (CS2+DOTA2 聚合)、Microsoft 365 官方 endpoints API (Teams 会议域名)、ngosang/trackerslist (BT tracker)、anti-AD 拦截列表按平台家族表反推流媒体域名 (只引入家族命中,其余十万条忽略)
- **7 个数据文件**:游戏域名 / 中继 IP 段 / 游戏端口 / 下载端口 / 流媒体域名 / 会议域名 / BT tracker 域名
- **抖音/快手已覆盖**:douyinvod.com / yximgs.com 等视频 CDN 实测命中 streaming 场景

## 数据集更新三层保护

- **防降级**:远端版本旧于本地时拒绝更新并明确提示 (版本比较按日期数值序,哈希尾缀不参与排序)
- **三层校验**:sha256 传输校验 → 语义校验 → 引擎烟测,全过才原子落地,任一失败自动回滚 (快照保留 20 份)
- **升级保护修复**:apk 升级覆盖数据集后,自愈逻辑不再误回滚 (旧版按哈希字符串序比较会判错方向)

## 智能模式页:自动检测新版

- 进入智能模式页自动检测识别库新版 (会话内一次 + 1 小时节流),有新版才亮提示条一键升级;无更新/网络失败完全静默不打扰
