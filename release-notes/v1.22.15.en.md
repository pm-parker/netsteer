# v1.22.15 — Security hardening, packet_steering coordination & stability fixes

This release lands the comprehensive security and runtime audit fixes from Issue #5 / PR #6, addressing input-validation vulnerabilities, OpenWrt native `packet_steering` drift conflicts, >4-core hex mask normalization, mode/rollback cleanup gaps, and `.apk` packaging ownership verification.

## Security hardening & least privilege

- **Strict UCI boundary checks (`netsteer-cfg`)**: validates `section` and `key` names against safe character classes to block cross-package or injection writes; supports both single-key lookup and full-section `get`.
- **Path-traversal & JSON-injection protection (`netsteer-irq`)**: validates IRQ IDs and hex CPU masks (rejecting traversal, out-of-range masks, and zero masks), sanitizes error responses, and preserves UCI state when the kernel rejects a write.
- **`eval` removal (`netsteer-qos`)**: replaces `eval`-based proxy API config parsing with pure POSIX `sed` compatible with OpenWrt BusyBox/musl, using non-greedy splitting so secrets containing `|` are preserved intact.
- **Least-privilege rpcd ACL**: removes unused `netsteer-check` from the rpcd exec whitelist.

## Native `packet_steering` coordination & POSIX locking

- **Zero-`flock` POSIX directory lock (`netsteer-apply`)**: serializes takeover/restore transitions using an atomic `mkdir` directory lock on tmpfs (`/tmp/netsteer/packet_steering.lock` by default, avoiding flash wear) with numeric PID liveness checks, 120s stale timestamp fallback, atomic `mv` stale reclaim, and integer `sleep 1` polling — fully compatible with default OpenWrt images without `flock`.
- **Snapshot-backed takeover & restore**: records the original `network.globals.packet_steering` state (`1`, `0`, or absent) before disabling it so NetSteer no longer fights OpenWrt 24.10+/25.12 native packet steering; cleanly restores the snapshot on `stop`, `clear`, or `preset off`, and clears the stopped marker when switching back to any active mode.
- **SQM CAKE option handling (`netsteer-mode`)**: removes stray literal single quotes when populating `nat dual-dsthost` / `nat dual-srchost` (plus legacy quoted writes in `netsteer-apply` presets), restores managed SQM options cleanly from snapshot, protects gaming queue scripts, and propagates `apply_standard` failures in `apply_p2p`.

## Stability, multi-core & self-heal reliability

- **Multi-core leading-zero mask normalization**: `netsteer-irq`, `netsteer-apply`, and `netsteer-check` normalize sysfs/proc hex masks (e.g. `08` vs `8`, `0f` vs `f`) via `norm_hex`, eliminating false drift alerts on >4-core routers.
- **Check & self-heal fixes (`netsteer-check`)**:
  - skips drift self-heal when `mode=off` or `enabled=0` so disabled configs are never re-applied every minute;
  - propagates `netsteer-apply` failures instead of recording false self-heal success;
  - prunes legacy excess incident logs back to the 20-file cap;
  - copies `manifest.tsv` alongside `*.txt` during upgrade feed recovery to stop infinite restore loops.
- **Idempotent nft cleanup & rollback (`netsteer-bulk` / `netsteer-qos` / `netsteer-snapshot`)**: deletes lingering `netsteer_bulk`/`netsteer_qos` nft tables when empty or disabled; rolls back UCI on `bulk add` nft failure; ensures `snapshot restore(off)` runs `apply clear`, `p2p off`, `qos reapply`, and `bulk reapply`.
- **Scene sensing & background bench**: preserves line 4 (`linked_prev`) in `qos_sense` edge-trigger state; hardens `netsteer-bench bg` with a pure POSIX atomic directory lock without non-POSIX fractional `sleep`.
- **Init script hygiene (`init.d/netsteer`)**: aligns with upstream `rc.common`, preserves custom user cron entries, and guards `/etc/init.d/cron restart` with `IPKG_INSTROOT` for offline image builds.

## Build & CI gates

- **Package ownership & permission gates**: `build-apk.sh` packages via `ns_as_root` (`root` / `unshare -r` / `sudo -n`), enforces `0755` on `99-netsteer`, and positively asserts `user: root` via `adbdump`.
- **Toolchain & regression tests**: hardens `fetch-apk-static.sh` against truncated archives and symlink escapes; adds runtime sandbox regression suites (`audit-fixes.test.sh`, `review-pr6.test.sh`) and `gitleaks` secret scanning; bundles updated dataset `2026.11.24-2777a0`.

## Upgrade notes

- Install over the existing `.apk` for your router architecture; native `packet_steering` and SQM queue options are snapshotted automatically on first start or mode switch.
