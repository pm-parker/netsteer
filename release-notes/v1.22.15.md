# v1.22.15 — 安全加固、packet_steering 协调与多核/自愈稳定性修复

本版基于全量安全与运行时深度审计（Issue #5 / PR #6），系统性修复了安全注入风险、原生 `packet_steering` 冲突、多核前导零误报、场景切换与回滚残留，以及 `.apk` 打包属主与 CI 校验链路问题。

## 安全加固与最小权限

- **UCI 配置写入边界校验（`netsteer-cfg`）**：严格限制 `section` 与 `key` 字符集，阻止跨包路径或非法字符注入；`get` 支持单键精确读取与整节查询。
- **IRQ 绑定防穿越与防 JSON 注入（`netsteer-irq`）**：强校验 IRQ 编号与掩码范围（拒绝路径穿越、超宽掩码、全零掩码），规范化错误输出防止 JSON 注入，内核拒写时返回 `ok:0` 且不污染 UCI。
- **消除 `eval` 风险（`netsteer-qos`）**：重构代理 API 端口与密钥解析逻辑，以纯 POSIX `sed` 取代 `eval`，非贪婪拆分保留含 `|` 字符的 `secret`，兼容 OpenWrt BusyBox/musl。
- **最小权限 ACL**：从 rpcd 白名单移除未在前端使用的 `netsteer-check`，收紧接口暴露面。

## 原生 `packet_steering` 协调与并发锁

- **零 `flock` 依赖的 POSIX 目录锁（`netsteer-apply`）**：以原子 `mkdir` 目录锁（默认落 `/tmp/netsteer/packet_steering.lock` 内存盘，支持 PID 存活判定、120s 超时兜底与原子 `mv` 僵尸锁回收）串行化接管与恢复，适配未内置 `flock` 的原生 OpenWrt。
- **快照接管与完整恢复**：服务启用或切入工作模式时快照原始 `network.globals.packet_steering`（区分 `1`、`0` 与缺失态）并置 `0`，避免与 OpenWrt 24.10+/25.12 原生 `packet_steering` 互相拉扯；停用、`clear` 或 `preset off` 时按快照精确恢复并标记停止态，切回工作模式时自动解除停止态重新接管。
- **SQM CAKE 参数修复（`netsteer-mode`）**：自动补齐 `nat dual-dsthost` / `nat dual-srchost` 时去掉多余字面单引号并按快照精确恢复；保护游戏队列脚本不被覆盖；`apply_p2p` 增加返回码校验。

## 稳定性、多核与自愈闭环

- **>4 核设备前导零掩码归一化**：`netsteer-irq`、`netsteer-apply`、`netsteer-check` 统一按 `norm_hex` 比对内核回读（如 `08` 与 `8`、`0f` 与 `f`），消除多核设备反复误报漂移。
- **巡检与自愈修复（`netsteer-check`）**：
  - `mode=off` / `enabled=0` 时跳过漂移自愈，不再每分钟把已关闭配置拉回；
  - `apply` 失败时原样透传错误，不伪造自愈成功记录；
  - 自动清理存量超限 `incidents` 日志至上限 20 份；
  - 升级恢复用户数据集时同步拷贝 `manifest.tsv`，根治重复恢复死循环。
- **nft 规则清表与回滚（`netsteer-bulk` / `netsteer-qos` / `netsteer-snapshot`）**：空列表或关闭态 `reapply` 幂等清理残留表；`bulk add` 在 `nft` 失败时回滚 UCI；`snapshot restore(off)` 完整联动 `apply clear`、`p2p off`、`qos reapply` 与 `bulk reapply`。
- **感知联动与后台测速**：修复 `qos_sense` 边沿触发丢失第 4 行 `linked_prev` 的问题；重构 `netsteer-bench bg` 原子目录锁，移除非 POSIX 浮点 `sleep` 并消除并发误删新锁竞态。
- **init 脚本规范化（`init.d/netsteer`）**：兼容官方 `rc.common` 生命周期，保留用户自定义 cron 行，并在 `IPKG_INSTROOT` 离线构包环境下隔离 `cron restart`。

## 构建与 CI 门禁

- **`.apk` 属主与权限门禁**：`build-apk.sh` 统一以 root 身份打包（支持 `root` / `unshare -r` / `sudo -n`），确保 `99-netsteer` 为 `0755` 且包内属主经 `adbdump` 正向断言为 `user: root`。
- **工具链与测试**：`fetch-apk-static.sh` 校验截断归档与非法符号链接；新增高保真运行时回归测试（`audit-fixes.test.sh`、`review-pr6.test.sh`）与 `gitleaks` 密钥扫描；包含最新上游识别库数据集 `2026.11.24-2777a0`。

## 升级说明

- 直接覆盖安装对应架构的 `.apk` 即可；原生 `packet_steering` 与 SQM 队列参数将在首次启动或切换模式时自动快照并纳入托管。
